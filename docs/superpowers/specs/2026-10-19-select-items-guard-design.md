# `SelectSingle` и `SelectMultiple`: некорректный `items` — выпуск `0.19.1`

Дата: 2026-10-19. Задача: https://github.com/boobooking/dashboard-ui-components/issues/1

## 1. Цель

Фильтры-списки не падают, если `items` — не массив или в массиве есть
элементы-необъекты. Сейчас:

- `SelectSingle` берёт `items ?? []`: не массив, не `null` и не `undefined`
  (объект, строка, число) доходит до `find` и `v-for` — ошибка рендера;
- оба компонента обращаются к `item.id` и `item.name` каждого элемента:
  `null` или `undefined` внутри массива — `TypeError`, фильтр не рисуется.
  `SelectMultiple` от не-массива уже защищён (`Array.isArray`).

Решение владельца (2026-10-19): завести задачу и выпустить исправление
отдельной версией `0.19.1` (согласие на публикацию дано).

## 2. Поведение

Как у меню пакета (`toMenuItems` в `src/menuItems.js`) — решение Claude
по прецеденту пакета:

- `items` не массив (в том числе `null` и `undefined`) — пустой список:
  кнопки фильтра нет, как при `[]`;
- элементы-необъекты (`null`, `undefined`, строки, числа, `true`)
  пропускаются; остальные пункты работают как обычно: выбор, галочки,
  надпись, поиск, клавиатура;
- массив из пропа не меняется; `id` в `modelValue` — как сейчас
  (у `SelectMultiple` `id` вне пунктов остаются в значении);
- Vue по-прежнему предупреждает о не-массиве по типу пропа; своих
  предупреждений компоненты не добавляют.

Вне рамок: некорректные поля пунктов-объектов (нет `id` или `name`, `name`
не строка и не приводится к строке), объекты с нестандартным поведением
(например, без `toString`) и другие компоненты.

## 3. README

- `SelectSingle`: в абзац про `items` — не массив — пустой список,
  элементы-необъекты пропускаются;
- `SelectMultiple`: фраза «`null` и `undefined` в `items` — пустой список»
  заменяется тем же правилом.

## 4. Тесты и приёмка

- `SelectSingle`: `items` — объект, строка, число: не падает, кнопки нет,
  одно предупреждение Vue о типе `items`; массив с `null`, `undefined`,
  строкой между пунктами — рисуются только пункты-объекты, выбор пункта
  отдаёт его `id`, выбранный пункт — в надписи.
- `SelectMultiple`: массив с `null`, `undefined`, строкой — рисуются только
  пункты-объекты, выбор работает, надпись считает только их, поиск (с
  `withSearch`) не падает.
- Вывод тестов чистый, кроме ожидаемых и проверенных предупреждений Vue.
- Браузер не нужен: изменение — в вычислении списка, вид не меняется.
