# DataTable в пакете dashboard-ui-components

Дата: 2026-10-06

## 1. Цель и рамки

Таблицы данных в дашбордах сверстаны вручную на каждой странице: обёртка,
шапка, строки, бейдж «Найдено …», пустое состояние и пагинация повторяются
в каждом проекте с мелкими расхождениями. Исправить вид таблицы — например,
добавить горизонтальную прокрутку или починить полосу прокрутки в Safari —
значит править каждую страницу каждого проекта.

Цель: один компонент `DataTable` в пакете, который содержит всю вёрстку
списка — бейдж с числом найденного, таблицу в обёртке, пустое состояние
и пагинацию. Страница отдаёт ему строки, описание столбцов и ответ
пагинации Laravel; особые ячейки — слотами.

В рамках задачи (выпуск пакета `0.12.0`):

- компонент `DataTable`;
- `Pagination` становится внутренним компонентом пакета и уходит
  из экспорта;
- меню `DropdownButtonWithAction` переезжает в верхний слой браузера
  (Popover API), чтобы его не обрезала таблица с горизонтальной
  прокруткой;
- внутренний модуль `src/popover.js`: положение всплывающего элемента
  у кнопки и закрытие при прокрутке и изменении размера окна;
- тесты, playground, README, выпуск `0.12.0`.

Вне рамок:

- перевод проектов на `DataTable`: у каждого проекта своя задача, спека
  и план (раздел 11);
- `Popup`, `DropdownButton`, `PickDay`: они живут в плашке фильтров,
  а не в таблице, и остаются как есть;
- плашка фильтров, кнопки «Создать …», табы — остаются на страницах;
- `awescode/domus`: чекбоксы массового выбора и списки внутри строки
  есть только там, и компонент их не поддерживает;
- перенос `TextPopover` из `certificates` в пакет — своя задача
  (`2026-10-06-text-popover-design.md`, раздел 6); она будет пользоваться
  `src/popover.js` из этой задачи.

## 2. Что показало исследование

Проверены все таблицы данных дашбордов: 53 таблицы в 10 проектах —
certificates 12 (таблица SMS на двух страницах), payments 2, cashback 6,
cashback-vetkit-backend 3, overweight 2, belarus 8, russia 7,
health-days-backend 5, awescode/domus 9.

**Пакет используют** только certificates (`^0.10.0`), cashback (`^0.10.0`)
и payments (`^0.9.0`). Остальные держат копии компонентов в `Shared/`:
`Pagination`, `SmallBadge`, `DropdownButtonWithAction`, `ConfirmationModal`.
`Pagination` из пакета импортирует только cashback (6 страниц);
certificates и payments пользуются своей копией `Shared/Pagination.vue`.

**Стек.** Vue 3.2–3.5; Tailwind 3 (belarus, russia, overweight, domus)
и 4 (остальные); Inertia `@inertiajs/vue3` 1.x–3.x, в overweight
и domus — старый `@inertiajs/inertia` 0.11.

**Общие классы во всех 53 таблицах** почти дословно совпадают:

- `table` — `min-w-full divide-y divide-gray-200`, `tbody` —
  `divide-y divide-gray-200`, `thead` без классов;
- строка шапки — `bg-gray-50 text-xs leading-4 font-medium text-gray-500 uppercase`;
- `th` — `px-6 py-3 text-left tracking-wider whitespace-nowrap`,
  с `text-right` у чисел и сумм и `text-center` у Email, ролей, иконок;
  пустой `th` над столбцом действий;
- строка — `bg-white even:bg-gray-50`; исключение — overweight
  Consumers, где цвет строки зависит от статуса (`bg-red-50`, `bg-green-50`);
- `td` — `px-6 py-4 whitespace-nowrap align-top`; столбцы с переносом
  без `whitespace-nowrap`; столбец действий — `text-right`; узкие
  столбцы — `w-px`;
- текст: основной `text-sm leading-5 font-medium text-gray-900`,
  вторичный `text-sm leading-5 text-gray-400`.

**Обёртки** — пять-шесть вариантов: карточка `shadow(-sm) border-b
border-gray-200 sm:rounded-lg` с `overflow-hidden` (широкая таблица
обрезается) или `overflow-y-visible` (таблица вылезает за страницу;
так сделано на всех страницах с меню действий, чтобы меню не обрезалось),
вокруг — цепочки Tailwind UI с отрицательными полями. Горизонтальная
прокрутка (`overflow-x-auto`) есть только в карточке группы certificates.

**Ячейки.** Текст в одну строку, текст в две и больше строк (имя + телефон,
событие + даты + код), дата строкой, число и сумма (обычно справа),
бейдж `SmallBadge`, ссылка Inertia, иконка с `title`, кнопка,
меню `DropdownButtonWithAction` с модалкой удаления (около 20 таблиц),
карточки питомцев, стопка «копировать ссылку», полоска срочности
слева в ячейке (belarus), подсказка с текстом (certificates).
Админские столбцы скрыты через `v-show` на `th` и `td`.

**Вокруг таблицы.** Бейдж «Найдено X: N» / «Не найдено X» (`SmallBadge`
indigo по центру) — почти на всех страницах; рядом с ним иногда ссылка
«скачать xlsx». Пагинация `Pagination` ниже (`mt-6`) по `{data, meta, links}`
Laravel; у 4–5 таблиц пагинации нет. Пустое состояние почти везде — таблица
скрыта `v-show`, остаётся бейдж «Не найдено …».

**Нигде не встречается:** сортировка, липкая шапка, итоговая строка,
состояние загрузки в таблице, раскрывающиеся строки, клик по строке,
мобильные карточки, скрытие столбцов по ширине экрана.

**Противоречие.** Горизонтальная прокрутка обрезает меню действий: панель
меню `Popup` — `absolute` внутри обёртки таблицы, а `overflow-x: auto`
делает обёртку прокручиваемой и по вертикали. Поэтому страницы с меню
держат `overflow-y-visible` и теряют прокрутку.

## 3. Решения и их источники

| Вопрос | Решение | Почему |
|---|---|---|
| Что входит в компонент | Бейдж «Найдено», таблица в обёртке, пустое состояние, пагинация | Решение владельца: всё между фильтрами и концом списка строится из одного ответа `{data, meta, links}`; фильтры, кнопки и табы слишком разные |
| Для каких проектов | Все дашборды mars и payments; без domus | Решение владельца |
| Широкая таблица | Прокручивается в своей карточке | Решение владельца; «едет таблица, а не страница» |
| Меню действий | `DropdownButtonWithAction` — на Popover API | Иначе прокрутка таблицы обрежет меню |
| Как описываются столбцы | Массив столбцов, особые ячейки — слоты `#cell-<key>` | Решение владельца (вариант A): выравнивание, перенос и ширина задаются у столбца один раз |
| Pagination | Внутренний компонент, не экспортируется | Решение владельца: пагинация используется только в таблицах |
| Скрытые столбцы | Поле `visible` у столбца | Админские столбцы; столбец не попадает в разметку |
| Цвет строки | `rowColor` → `'red'`, `'green'` или `null` | Классы строки от страницы проиграли бы полосатости `even:` пакета |
| Выравнивание строки | Всегда по верху | Так в большинстве таблиц |
| Сброс пакета | Корень без `bb-dashboard-ui` | Как `PageCard`: в ячейках много разметки приложения |

## 4. Компонент `DataTable`

### 4.1. Пример

```vue
<data-table
    :rows="orderObjects"
    :columns="columns"
    row-key="uuid"
    :meta="orders.meta"
    :links="orders.links"
    found-text="Найдено ордеров"
    empty-text="Не найдено ордеров"
>
    <template #results-actions>
        <download-link :url="exportUrl" title="скачать xlsx"/>
    </template>
    <template #cell-status="{ row }">
        <small-badge :text="row.statusLabel" :color="row.statusColor"/>
    </template>
</data-table>
```

```js
columns() {
    return [
        { key: 'phone', label: 'Телефон' },
        { key: 'vendor', label: 'Вендор / Сертификат', secondary: (row) => row.certificate },
        { key: 'amount', label: 'Номинал', align: 'right', muted: true },
        { key: 'status', label: 'Статус' },
        { key: 'cost', label: 'Стоимость', align: 'right', visible: this.isAdmin },
        { key: 'comment', label: 'Состояние', wrap: true },
        { key: 'actions', align: 'right', narrow: true },
    ];
},
```

### 4.2. Пропы

| Проп | Тип | По умолчанию | Описание |
|---|---|---|---|
| `rows` | `Array` | обязателен | Строки: обычные объекты или модели страницы |
| `columns` | `Array` | обязателен | Описание столбцов, раздел 4.3 |
| `rowKey` | `String`, `Function` | обязателен | Имя поля ключа строки или функция `row => ключ` |
| `meta` | `Object` | `null` | `meta` пагинации Laravel: `{ from, to, total }` |
| `links` | `Object` | `null` | `links` пагинации Laravel: `{ prev, next }` |
| `foundText` | `String` | `null` | Текст бейджа, когда есть записи: «Найдено ордеров» → «Найдено ордеров: 100» |
| `emptyText` | `String` | `null` | Текст бейджа без записей: «Не найдено ордеров» |
| `variant` | `String` | `"page"` | `"page"` или `"card"`, с `validator` (раздел 4.5) |
| `rowColor` | `Function` | `null` | `row => 'red' \| 'green' \| null` — цвет строки (раздел 4.6) |
| `lang` | `String` | `null` | `"ru"` или `"en"` — тексты пагинации; через `withLang` |

Событий нет: ссылки пагинации идут через `navigate` плагина, как сейчас.

### 4.3. Столбец

Элемент массива `columns` — объект:

| Поле | По умолчанию | Описание |
|---|---|---|
| `key` | обязателен | Строка: имя слота `cell-<key>` и поле значения по умолчанию |
| `label` | `""` | Заголовок столбца; пустой — у столбца действий |
| `value` | `row => row[key]` | Функция строки → основной текст ячейки |
| `secondary` | нет | Функция строки → серая вторая строка |
| `muted` | `false` | Основной текст серый (`text-gray-400`) — даты, статусы, суммы |
| `align` | `"left"` | `"left"`, `"center"` или `"right"` — для `th` и `td` |
| `wrap` | `false` | Текст в ячейках переносится (нет `whitespace-nowrap`) |
| `narrow` | `false` | Ширина по содержимому (`w-px`) у `th` и `td` |
| `visible` | `true` | `false` — столбца нет: ни заголовка, ни ячеек, ни слота |

Скрытый столбец — только отображение, не защита: данные, которые не должен
видеть пользователь, сервер не отдаёт в ресурсе.

### 4.4. Слоты

- `#cell-<key>="{ row, index }"` — своя разметка ячейки столбца `key`.
  Слот заменяет ячейку по умолчанию; классы `td` — отступы, выравнивание,
  перенос, `relative` — остаются за компонентом. `index` — номер строки
  на странице, с нуля.
- `#results-actions` — рядом с бейджем справа от него; рисуется, только
  когда записей больше нуля (ссылки «скачать xlsx»).

### 4.5. Строение и варианты

```
div (корень; class и атрибуты страницы — сюда)
├─ строка бейджа: SmallBadge color="indigo" + слот #results-actions
├─ div (простой блок)
│  └─ div (обёртка: overflow-x-auto + оформление варианта)
│     └─ table
└─ Pagination (внутренний), если задан meta
```

Простой блок между корнем и обёрткой с прокруткой — обход Safari: элемент
flex-колонки с `overflow-x-auto` Safari считает без горизонтальной полосы
прокрутки, и полоса съедает низ таблицы, добавляя вертикальную. Корень
компонента часто стоит в flex-колонке страницы или карточки.

| | `page` | `card` |
|---|---|---|
| Где | Отдельный список на странице | Таблица внутри карточки страницы (табы карточки группы certificates) |
| Обёртка таблицы | `overflow-x-auto shadow-sm border-b border-gray-200 sm:rounded-lg` | `overflow-x-auto border-t border-gray-200` |
| Строка бейджа | `my-4` | без отступа сверху |
| Блок таблицы | — | `mt-4` после бейджа |
| Пагинация | `mt-6` | `mt-4` |

Строка бейджа: `flex justify-center items-center space-x-2`. Нет текста
бейджа для текущего случая и нет слота — строки бейджа нет, и в `card`
у блока таблицы нет отступа сверху.

Таблица не растягивается на мобильном за края контейнера, как нынешние
обёртки с отрицательными полями (`-mx-4 sm:-mx-6 lg:-mx-8`): она занимает
ширину контейнера и прокручивается в своей карточке.

### 4.6. Классы

Все — с префиксом `bb:`.

- `table`: `min-w-full divide-y divide-gray-200 border-collapse`;
- строка шапки: `bg-gray-50`;
- `th`: `px-6 py-3 text-xs leading-4 font-medium text-gray-500 uppercase
  tracking-wider whitespace-nowrap`, `scope="col"`, плюс выравнивание
  столбца, плюс `w-px` у `narrow`;
- `tbody`: `divide-y divide-gray-200`;
- строка: `bg-white even:bg-gray-50`; при `rowColor` → `'red'` — `bg-red-50`,
  `'green'` — `bg-green-50`, без полосатости;
- `td`: `px-6 py-4 align-top relative text-sm leading-5`, плюс
  `whitespace-nowrap` без `wrap`, плюс выравнивание, плюс `w-px`
  у `narrow`.

Вид не зависит от preflight приложения: `border-collapse`, начертание
и выравнивание текста `th` компонент задаёт сам, а не берёт от браузера
или preflight. `relative` у `td` нужен слотам с абсолютными элементами
внутри ячейки (полоска срочности belarus) и держит внутри ячейки скрытые
подписи `sr-only`: без него они позиционируются от ближайшего предка
и выходят из обёртки с прокруткой.

### 4.7. Ячейка по умолчанию

```
div: font-medium + text-gray-900 (или text-gray-400 при muted) — value(row)
div: text-gray-400 — secondary(row), если результат не пустой
```

`null` и `undefined` из `value` — пустая ячейка; пустая вторая строка
не рисуется.

### 4.8. Число записей, бейдж, пустое состояние, пагинация

- Число записей — `meta.total`, если `meta` задан и `total` — число;
  иначе длина `rows`.
- Записей больше нуля — бейдж с `«{foundText}: {число}»`, если `foundText`
  задан, и слот `#results-actions`.
- Записей нет — бейдж с `emptyText`, если задан; таблицы и пагинации нет.
- Таблица рисуется, когда `rows` не пуст. Страница за последней (записи
  есть, `rows` пуст) — бейдж «Найдено», таблицы нет, пагинация есть:
  по ней можно вернуться назад.
- Пагинация — внутренний `Pagination` с `meta`, `links` и `lang`, если
  `meta` задан; её правило «нет записей — ничего не рисует» сохраняется.

### 4.9. Устойчивость к значениям

По правилам пакета компонент не падает ни на каком значении пропа:

- `rows` не массив — пустой список; `columns` не массив — столбцов нет;
- элемент `columns` без строкового `key` или не объект — пропускается;
- `align` вне списка — `"left"`; `rowColor` вернула иное — строка без цвета;
- `rowKey` — функция, бросившая исключение или вернувшая `null`
  или `undefined`, либо имя поля, которого нет, — ключ строки берётся
  по её номеру;
- `value` и `secondary` не функции — значение по умолчанию и нет второй
  строки;
- `variant` вне списка — `validator` предупреждает в dev, компонент
  рисует `"page"`.

### 4.10. SSR

Компонент только рисует: `window` и `document` не трогает. В
`tests/ssr.test.js` и `tests/hydration.test.js` он попадает через
`tests/ssrFixtures.js` с двумя строками, `meta` и `links`.

## 6. `DropdownButtonWithAction` на Popover API

### 6.1. Разметка

- Кнопка-стрелка получает `popovertarget` с id панели из `useId()`.
- Панель меню — `<div popover="auto">` с классами
  `bb:m-0 bb:inset-auto bb:w-56 bb:rounded-md bb:shadow-lg bb:bg-white
  bb:ring-1 bb:ring-black/5`, `role="menu"`, `aria-orientation="vertical"`,
  `aria-labelledby` на стрелку — как сейчас. `m-0 inset-auto` снимают
  умолчания браузера для `[popover]`.
- `Popup` и `Overlay` этим компонентом больше не используются; анимация
  появления меню (`scale-95` → `scale-100`) уходит вместе с `Popup`.

### 6.2. Открытие и закрытие

Открывает и закрывает браузер — по `popovertarget` и правилам
`popover="auto"`: клик по стрелке, повторный клик, клик вне меню, Escape,
открытие другого меню. Компонент добавляет:

- клик по пункту меню (любой клик внутри панели) — меню закрывается:
  в верхнем слое открытое меню легло бы поверх модалки, которую открывает
  пункт «Удалить»;
- прокрутка любого блока страницы, кроме самой панели, и изменение
  размера окна — меню закрывается (`src/popover.js`).

### 6.3. Положение

При `beforetoggle` с `newState === 'open'` — по правилам `src/popover.js`
от кнопки-стрелки: правый край меню по правому краю стрелки, зазор 4 px
(как `mt-1`), вниз или вверх — где больше места, в пределах окна с отступом
8 px; высота ограничена местом, длинное меню прокручивается внутри.
`placePopover` получает `maxWidth` 224 px — ширину `w-56`: у стрелки ближе
224 px к левому краю окна меню сужается до места слева и не выходит
за окно.

### 6.4. `v-model`

Контракт прежний. `update:modelValue` эмитится, только когда меню открыл
или закрыл сам компонент или браузер: стрелка, клик вне, Escape, клик
по пункту, прокрутка, изменение размера окна. Значение от родителя
принимается молча: `true` — `showPopover()`, `false` — `hidePopover()`,
а событие `toggle` от такого вызова не эмитится обратно. Без `v-model`
меню работает само по себе.

Браузер доставляет `toggle` не сразу, а отдельной задачей, и быстрые
переключения подряд объединяет в одно событие с последним `newState`.
Поэтому подавление ответного события не держится на временном флаге
вокруг `showPopover()` и `hidePopover()`: компонент хранит текущее
значение меню и при `toggle` эмитит `update:modelValue`, только если
`newState === 'open'` расходится с ним, обновив его перед эмитом.
Значение от родителя записывается в это поле сразу при его приходе.

### 6.5. Без Popover API

Браузеры старше Safari 17, Chrome 114 и Firefox 125: `showPopover`,
`hidePopover` и `:popover-open` зовутся только после проверки поддержки,
исключений нет; панель видна в потоке ячейки всегда.

## 7. `src/popover.js`

Внутренний модуль, не экспортируется. Функции:

- `canControlPopover(element)` — у элемента есть `showPopover`;
- `isPopoverOpen(element)` — `canControlPopover(element)` и
  `element.matches(':popover-open')`;
- `placePopover(anchor, popover, { maxWidth })` — ставит инлайн-стилями
  `top` или `bottom`, `right`, `left: auto`, `max-height` и, если задан
  `maxWidth`, `max-width`: правый край по правому краю `anchor`, зазор
  4 px, сторона с большим местом, отступ от края окна 8 px, ширины и высоты
  не меньше нуля (`Math.max(0, …)`); размеры окна —
  `document.documentElement.clientWidth` и `clientHeight`;
- `closeOnScrollAndResize(popover, close)` — вешает на `window` `scroll`
  (`capture: true`, `passive: true`; события, чей `target` — сама панель
  или её потомок, пропускаются) и `resize`, зовущие `close()`; возвращает
  функцию, снимающую оба слушателя.

`TextPopover` при переносе в пакет использует этот модуль со своим
`maxWidth` 384 px.

## 8. Тесты

Порядок пакета: `npm test` и `npm run build` → проверка в certificates
через `npm pack` и `npm install --no-save <архив>` (раздел 12) →
`chore:`-коммит версии `0.12.0` в `package.json` и двух местах
`package-lock.json` → пуш `main`, зелёный `Test` по полному SHA → тег

импортируют `Pagination` из пакета, и обновиться на `0.12.0` cashback

certificates и payments пользуются своей копией `Shared/Pagination.vue`:
им обновление ничего не ломает, перевод на `DataTable` — плановый.

## 13. Принятые риски

- **Браузеры.** Меню действий требует Popover API: Safari 17+, Chrome 114+,
  Firefox 125+. В старых браузерах панель меню видна в ячейке всегда.
- **Прокрутка закрывает меню.** Оператор, прокрутивший таблицу с открытым
  меню, откроет его снова.
- **Без отрицательных полей.** На мобильном таблица не растягивается
  до краёв экрана, как сейчас в части проектов.
- **Ломающий выпуск.** `0.12.0` убирает `Pagination` из экспорта:
  cashback обновляется только вместе с переводом шести списков.
- **Анимация меню** появления и скрытия уходит.
