# Pagination, NavigationMenuElement и языки

Дата: 2026-09-27

## 1. Цель и рамки

Две задачи одного выпуска `0.8.0`.

**Перенос двух компонентов.** `Pagination` и `NavigationMenuElement` живут
копиями в девяти проектах: у `Pagination` пять вариантов, у
`NavigationMenuElement` — четыре. Все копии завязаны на `Link` из Inertia, из-за
чего первый выпуск пакета их и отложил. Пакет не должен зависеть ни от Inertia,
ни от какого-либо роутера.

**Языки.** В payments русский текст запрещён, а в пакете есть русские тексты.
Язык компонентов задаётся: по умолчанию `ru`, при `en` все тексты пакета —
английские.

В рамках задачи:

- плагин `dashboardUi` для подключения к приложению: язык и функция перехода
  по ссылке;
- словари `ru` и `en` для всех текстов пакета и проп `lang` у каждого
  компонента с текстами;
- компоненты `Pagination` и `NavigationMenuElement`;
- тесты, playground, README, выпуск `0.8.0`;
- перевод cashback на новые компоненты как первого потребителя.

Вне рамок: перевод остальных проектов (payments, certificates, russia,
belarus и другие) — отдельные задачи; номера страниц в `Pagination` — их не
рисует ни одна копия; смена языка «на лету»; формат даты для `en`.

Без плагина пакет ведёт себя как `0.7.0`: русский язык, ссылки — обычные `<a>`.

## 2. Что показало исследование копий

**`Pagination`.** Данные везде одни: Laravel API Resource, то есть `links`
(`prev`, `next`) и `meta` (`from`, `to`, `total`). Номера страниц не рисует ни
одна копия, только «Предыдущая» и «Следующая». Фильтры в адресах страниц
сохраняет бэкенд (`withQueryString()`), поэтому компоненту достаточно простого
`href`; опциями Inertia (`preserve-state` и т. п.) никто не пользуется. Вызов
везде один: `<pagination class="mt-6" :meta="x.meta" :links="x.links"/>`.
Варианты:

- A — cashback, cashback-vetkit-backend, certificates, health-days-backend:
  русские подписи, стрелки из heroicons v1, текст «Показаны результаты» скрыт
  на узком экране;
- B — payments: то же на английском;
- C — overweight: как A, но на старом `@inertiajs/inertia-vue3`;
- D — russia: как A, стрелки текстом `←`/`→`;
- E — belarus: другая вёрстка, текст не скрыт на узком экране.

**`NavigationMenuElement`.** В четырёх вариантах из пяти контракт один: `url`,
`name`, `isActive`; различия — только `focus:outline-hidden`/`-none` и старый
импорт в overweight. belarus вместо `url` принимает имя маршрута и сам вызывает
`route()`.

**Переходы Inertia.** Проверено по исходникам `@inertiajs/vue3` 3.6.1 и
вживую на cashback во временной ветке: `<a href>`, у которого обычный клик
вызывает `router.visit(href)`, ведёт себя как `Link` с одним `href` во всех
сценариях — переход XHR с заголовком `X-Inertia` без перезагрузки, адрес и
запись в истории, прокрутка наверх, индикатор загрузки, фильтры в адресе,
«назад» и «вперёд», Enter, пункт меню шапки; клики с Ctrl/Cmd/Shift и средней
кнопкой не перехватываются, браузер открывает вкладку сам; ошибок в консоли
нет. `router.visit(href)` берёт те же умолчания, что `Link` без опций
(`replace`, `preserveScroll`, `preserveState` — `false`). Отличия: `Link`
начинает переход на `mouseup`, а не на `click`, и ставит атрибут
`data-loading` на время перехода — его не использует ни один проект.

## 3. Плагин `dashboardUi`

```js
import { dashboardUi } from '@boobooking/dashboard-ui-components'

createApp(...).use(dashboardUi, {
    lang: 'en',
    navigate: (href) => router.visit(href),
})
```

Оба параметра необязательны.

- `lang` — `'ru'` (по умолчанию) или `'en'`. Любое другое значение, включая
  явные `null` и `undefined`, роняет `app.use` с ошибкой, называющей
  допустимые значения: неверный язык ловится сразу, а не проявляется русским
  текстом в английском приложении. «Не передан» — только отсутствующий ключ
  (проверка `Object.hasOwn`).
- `navigate(href)` — функция перехода приложения: для Inertia
  `router.visit(href)`, для Vue Router `router.push(href)`. Переданное
  значение, не являющееся функцией, включая явные `null` и `undefined`, —
  ошибка в `app.use`; «не передан» — только отсутствующий ключ. Без неё ссылки пакета работают как обычные `<a>` с
  полной загрузкой страницы.

Плагин кладёт настройки в `provide` приложения; компоненты читают их через
`inject` со значением по умолчанию `{ lang: 'ru', navigate: null }`, поэтому
без плагина ничего не ломается. Ключ `provide` — внутренний, наружу не
экспортируется.

`navigate` задаётся только на приложение: переопределять переход на отдельном
вызове никому не нужно.

## 4. Языки и тексты

Все тексты пакета лежат в одном внутреннем модуле `src/i18n.js` — словари
`ru` и `en` с одинаковым набором ключей. Язык компонента: проп `lang`, если
задан, иначе язык плагина, иначе `ru`.

Проп `lang` (`'ru'` | `'en'`, `validator`, по умолчанию не задан) получают
компоненты с текстами: `ConfirmationModal`, `DownloadLink`,
`DropdownButtonWithAction`, `PickDay`, `SelectDateInterval`, `Pagination`.

| Где | `ru` | `en` |
|---|---|---|
| `ConfirmationModal`, кнопка отмены по умолчанию | Отмена | Cancel |
| `DownloadLink`, подпись по умолчанию | Скачать | Download |
| `DropdownButtonWithAction`, подпись стрелки для скринридера | Открыть меню | Open menu |
| `PickDay`, кнопки календаря | Предыдущий месяц / Следующий месяц | Previous month / Next month |
| `PickDay`, месяцы | Январь … Декабрь | January … December |
| `PickDay`, дни недели | Воскресенье … Суббота; Вс … Сб | Sunday … Saturday; Sun … Sat |
| `SelectDateInterval`, подсказки полей | от / до | from / to |
| `Pagination` | Предыдущая / Следующая / Показаны результаты X - Y из Z | Previous / Next / Showing X - Y of Z results |

Английские тексты `Pagination` — из копии payments. Русские совпадают с
нынешними: для `ru` вид не меняется.

**Явный текст главнее языка.** Умолчания `cancelButtonText` у
`ConfirmationModal` и `title` у `DownloadLink` становятся «не задано»: если
приложение передало текст, берётся он, иначе — текст языка.

**Вложенность.** `SelectDateInterval` передаёт внутренним `PickDay` свой
итоговый язык, так что проп `lang` на интервале действует и на календари.

**Что не зависит от языка.** Формат даты — `дд.мм.гггг` в обоих языках: это
формат значения, которое уходит на бэкенд, а не текст. Неделя начинается с
понедельника (`firstDay: 1`) в обоих языках. `RussianMobileFilter` своих
текстов не имеет.

**Ограничение.** Календарь `PickDay` берёт язык при монтировании: Pikaday
собирается один раз. Смена языка после монтирования в календаре не
отражается; язык приложения на лету не меняется. Записывается в README.

## 5. Переход по ссылке

Компоненты пакета рисуют настоящий `<a :href>` — адрес виден, ссылку можно
открыть в новой вкладке, копировать, у неё работает Enter.

Внутренний модуль `src/navigation.js` решает, перехватить ли клик, по тем же
правилам, что `shouldIntercept` в Inertia: клик перехватывается, только если
он не отменён ранее (`defaultPrevented`), это левая кнопка (`button === 0`),
не зажаты Alt, Ctrl, Meta, Shift и у ссылки нет `target`, кроме `_self`.
Перехваченный клик отменяется (`preventDefault`) и уходит в `navigate(href)`
плагина. Без `navigate` ничего не перехватывается: браузер идёт по ссылке сам.

Модуль используют оба новых компонента; наружу он не экспортируется.

## 6. `Pagination`

Вёрстка варианта A (`cashback/resources/js/Shared/Pagination.vue`), классы с
префиксом `bb:`.

- `links` — объект с `prev` и `next`, `meta` — объект с `from`, `to`, `total`,
  как их отдаёт Laravel API Resource. Оба обязательны, но на `null`,
  `undefined` и отсутствующих ключах компонент не падает (Vue при этом
  предупредит о типе обязательного пропа).
- **Нет записей** — `meta` не задан или `meta.total` не число больше нуля:
  компонент ничего не рисует.
- **Записи есть** — рисуется `<nav>`. «Предыдущая» и «Следующая» — только если
  в `links.prev` / `links.next` непустой адрес; при `links: null` кнопок нет,
  строка результатов остаётся. В варианте A при отсутствующем ключе
  рисовалась ссылка на `#`; этого больше нет.
- Посередине — «Показаны результаты X - Y из Z», скрыто на узком экране, как
  сейчас; только когда в `meta` есть числовые `from` и `to`, иначе строки
  нет — нули вместо диапазона не выводятся.
- Стрелки — внутренние SVG-иконки с теми же контурами, что
  `ArrowNarrowLeft`/`ArrowNarrowRight` heroicons v1: вид не меняется, heroicons
  не нужен ни пакету, ни потребителю.
- Ссылки — по разделу 5.
- Корень один (`<nav>`), атрибуты вызова (`class="mt-6"`) ложатся на него
  штатно.
- Проп `lang` — по разделу 4.

## 7. `NavigationMenuElement`

Контракт тот же, что в пяти проектах, — замена в шапке сводится к импорту.

- `url` (обязательный), `name` (обязательный), `isActive` (по умолчанию
  `false`);
- `<a :href="url">`, переход — по разделу 5;
- классы активного и обычного состояния — из варианта A, с префиксом `bb:`;
- своих текстов нет, подпись передаёт приложение, проп `lang` не нужен.

belarus, где передаётся имя маршрута, при своём переходе будет передавать
`:url="route(…)"` — вне этой задачи.

## 8. Тесты

- **Перехват клика** (`src/navigation.js`, среда node): таблица случаев —
  обычный левый клик перехватывается; Alt, Ctrl, Meta, Shift, средняя кнопка,
  `target="_blank"`, уже отменённое событие — нет; `target="_self"` —
  перехватывается.
- **`Pagination`** (happy-dom): кнопки по `links`; при `links: null` и записях
  — строка результатов без кнопок; без `from`/`to` — кнопки без строки
  результатов; при `total = 0`, `meta: null`, `meta` без ключей — ничего не
  рисуется; обычный клик по «Следующая»
  вызывает `navigate` с адресом и отменяет событие, Ctrl-клик — не вызывает и
  не отменяет; без плагина клик не отменяется.
- **`NavigationMenuElement`**: те же проверки клика.
- **Плагин и языки**: без плагина — `ru`; `en` через плагин; проп `lang`
  главнее плагина; явный `cancel-button-text` главнее языка; неизвестный
  `lang`, `navigate`, не являющийся функцией, и явные `null` и `undefined`
  в любом из них роняют `app.use`; язык `SelectDateInterval` — и из плагина, и из пропа —
  доходит до подсказок и до обоих вложенных календарей; открытый календарь
  `PickDay` показывает английское название месяца.
- Разметку новых компонентов проверяет существующий `tests/utilityPrefix.test.js`.
- Диагностики тестов проверяются через `npm test -- --reporter=verbose`.
