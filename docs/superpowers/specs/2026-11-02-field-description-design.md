# Описание поля формы

Дата: 2026-11-02

## 1. Цель и рамки

Полям форм нужен поясняющий текст под полем. Сейчас страницы пишут его вручную,
а вид и отступ у каждой свой. Описание задаётся пропом, вид задаёт один приватный
компонент: чтобы поменять внешний вид, достаточно поменять его.

В рамках задачи:

- проп `description` и слот `description` у десяти полей форм;
- приватный компонент описания;
- связь поля с описанием для скринридера;
- тесты, Playground, README.

Вне рамок:

- версии полей для фильтров (`SelectSingleFilter`, `AmountIntervalFilter` и другие);
- сообщения об ошибках: `ErrorMessages` остаётся плашкой формы;
- перевод страниц проектов, в том числе payments;
- подъём версии, тег и публикация: только по слову владельца.

## 2. Что показало исследование

- Поля форм: `FormInput`, `SelectSingleForm`, `SelectCurrencyForm`,
  `SelectMultipleForm`, `SelectDateForm`, `SelectDateIntervalForm`, `AmountForm`,
  `AmountIntervalForm`, `SelectSingleCards`, `SelectMultipleList`. Подпись у всех
  одна: `text-sm font-medium leading-5 text-gray-700`.
- `SelectCurrencyForm` — обёртка над `SelectSingleForm`: проп и слот он передаёт
  насквозь.
- В payments описание с `<Link>` в середине текста стоит на двух страницах
  (`PaymentAgents/Create.vue`, `General.vue`): `text-sm text-gray-500`, «There are no
  working countries yet. Add them in Settings first». Текст показывается по условию.
- Ядра принимают проп `labelledBy` и ставят его на кнопку или поле:
  `DropdownButton`, `SelectDate`, `AmountCurrency`. Рядом ложится `describedBy`.
- Обычный текстовый проп не передаст `<Link>`: вставка готового HTML небезопасна, а
  компонент Inertia в ней не работает.
- Ресет пакета действует и на разметку слота: ссылка в описании берёт цвет текста
  и не подчёркнута, пока страница не задаст своё оформление.
- `setup()` в миксине Vue не вызывает, поэтому `useId()` остаётся в компонентах.

## 3. Решения и их источники

| Решение | Источник |
| --- | --- |
| Проп с описанием у всех полей форм, текст появляется под полем, если проп заполнен | владелец |
| Вид одинаковый у всех, его задаёт один приватный компонент | владелец |
| Текст меньше подписи и серее подписи | владелец |
| Текст в пропе, ссылка и другая разметка — в слоте `description` | владелец |
| Имя `description`; в рамках все десять полей, включая `SelectSingleCards` и `SelectMultipleList` | автор, показано владельцу |
| 12 px, `gray-500`, отступ от поля 4 px | автор, показано владельцу |
| Поле связано с описанием для скринридера | автор, показано владельцу |
| Стиль ссылки в слоте задаёт страница | автор, показано владельцу |
| Пустой проп равен отсутствию описания | автор, показано владельцу |
| Слот важнее пропа, если заданы оба | автор |
| В `AmountForm` описание связано с полем суммы, а не с блоком валюты | автор |
| Описание есть, если слот передан; пустой по содержимому слот страница не передаёт | автор |
| Вид описания один при любом состоянии поля, в том числе `disabled` | автор |

## 4. API

### 4.1. Пример

```vue
<form-input v-model="email" label="Email" description="На этот адрес придёт письмо" />

<select-single-form
    v-model="country"
    label="Country"
    :items="countryItems"
    :description="countryItems.length === 0 ? 'Нет доступных стран' : null"
/>

<select-single-form v-model="country" label="Country" :items="countryItems">
    <template v-if="countryItems.length === 0" #description>
        Add them in <Link :href="route('settings.countries')" class="text-indigo-500">Settings</Link> first.
    </template>
</select-single-form>
```

### 4.2. Проп и слот

| Что | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `description` | `String` | `null` | Текст под полем |
| слот `description` | разметка | — | Описание с разметкой: ссылка, несколько частей текста |

- Если слот передан, описание показывает его, а проп не используется.
- `null`, `undefined` и пустая строка — описания нет, поле выглядит как сейчас.
- Значение не строкой Vue отмечает предупреждением о пропе, описания нет, компонент
  не падает.
- Текст пропа выводится как текст: разметка в нём не срабатывает.
- `v-if` на шаблоне слота работает: описание появляется и исчезает по условию.
  Описание считается заданным, если слот передан. Условие ставится на шаблон слота,
  а не внутрь него: иначе останется пустой блок.

## 5. Вид

| Свойство | Значение |
| --- | --- |
| Место | под полем, на всю его ширину |
| Отступ от поля | 4 px |
| Текст | 12 px, высота строки 16 px, обычное начертание |
| Цвет | `gray-500` |

- Длинный текст переносится внутри ширины поля. Длинное слово без пробелов не
  раздвигает форму.
- Описание стоит под всей группой: у полей из двух частей и у карточек — под обеими
  частями или под всеми карточками.
- Если у `SelectSingleCards` и `SelectMultipleList` нет пунктов, подпись и описание
  остаются.
- Ссылка в слоте нажимается мышью и с клавиатуры: на содержимом описания нет
  `pointer-events-none`.
- Высота самого поля и отступ между подписью и полем не меняются.
- Вид один при любом состоянии поля: у `disabled` описание не гаснет.
- Сообщений об ошибках внутри полей нет, `ErrorMessages` стоит на странице, поэтому
  порядка «описание и ошибка» внутри компонента не возникает.

## 6. Доступность

Описание получает `id`, поле — `aria-describedby` с этим `id`. Без описания атрибута
нет. У `SelectDateForm` кнопка и поле даты — две отдельные остановки фокуса, поэтому
связаны оба элемента, как и `aria-labelledby`.

| Поле | Куда ставится `aria-describedby` |
| --- | --- |
| `FormInput` | `<input>`. Значение, переданное страницей, сохраняется: оба `id` через пробел |
| `SelectSingleForm`, `SelectCurrencyForm`, `SelectMultipleForm` | кнопка поля. Без пунктов кнопки нет: описание остаётся, связи нет; с появлением пунктов связь появляется |
| `SelectDateForm` | кнопка календаря и поле даты |
| `AmountForm` | оба поля суммы, основная часть и копейки, если они есть; блок валюты без связи |
| `SelectDateIntervalForm`, `AmountIntervalForm` | `role="group"` |
| `SelectSingleCards`, `SelectMultipleList` | `role="radiogroup"` и `role="group"`; без пунктов группы нет, связи тоже |

## 7. Устройство

Ниже — намеченная раскладка; имена и детали остаются за исполнителем, если
поведение совпадает с разделами 4–6.

- `src/components/FieldDescription.vue` — приватный компонент: `id`, текст или слот,
  все классы вида. Из пакета не экспортируется. Классы вида описания есть только здесь.
- `src/fieldDescription.js` — миксин `withFieldDescription`: проп `description` и
  метод «есть ли описание», который смотрит на `$slots.description` и проп. Метод,
  а не вычисляемое свойство: `$slots` не реактивен.
- `id` описания строится из `useId()`, который уже есть в компоненте: `labelId`,
  а у `FormInput` и `AmountForm` — `id` поля. Новый `useId()` не нужен. `SelectCurrencyForm`
  своего `id` не заводит: описание рисует `SelectSingleForm`.
- `DropdownButton`, `SelectSingle`, `SelectMultiple`, `SelectDate`, `AmountInput` —
  проп `describedBy` рядом с `labelledBy`: одна строка с `id`. Это внутренние компоненты,
  объединять значение не с чем.
- `SelectCurrencyForm` передаёт проп и слот в `SelectSingleForm`; слот передаётся,
  только если он задан, иначе `SelectSingleForm` увидит пустой слот.

## 8. README, Playground, тесты

**README.** Общий раздел об описании поля: проп, слот, пример со ссылкой, вид. В таблицу
пропов каждого из десяти компонентов — строка `description`. Раздел «Языки» не
меняется: текст задаёт страница.

**Playground.** Раздел с десятью полями с описанием, пример со ссылкой в слоте,
длинный текст.

**Тесты (Vitest).** Одна таблица на все десять компонентов:

- текст пропа показан под полем, в том же экземпляре вида;
- `null`, пустая строка и отсутствие пропа — описания нет, атрибута `aria-describedby` нет;
- слот показан, проп при этом не показан;
- `v-if` на слоте: описание появляется и исчезает;
- текст с разметкой выводится как текст;
- не строка — предупреждение и без ошибок;
- `aria-describedby` на элементе из таблицы раздела 6 ссылается на `id` описания;
- два экземпляра одного поля: `id` описаний разные.

Отдельно по таблице раздела 6: `AmountForm` с копейками и без них; три выпадающих
поля при переходе пунктов `[] → items → []`; пустые `SelectSingleCards`
и `SelectMultipleList`; заблокированное поле сохраняет связь.

Отдельно: `FormInput` сохраняет `aria-describedby` страницы; `SelectCurrencyForm`
без слота не показывает пустое описание; `FormInput` при смене `aria-describedby`
страницы и своего `id`; сторож — описание каждого поля нарисовано `FieldDescription`,
а на его вызовах нет своих классов; фикстуры SSR с описанием, в том числе слот;
`tests/exports.test.js` без изменений.

**Тесты (Playwright, Chromium и WebKit).** Обе страницы Playground, все десять полей:
размер 12 px, цвет `gray-500`, отступ 4 px от нижнего края поля. Ссылка в слоте
нажимается мышью и с клавиатуры. Длинное слово не шире поля.

**Приёмка.** В Chrome — исполнитель, в Safari — владелец, в Playground.
